Important notice:
- Almost all skills of the dancer tree are “timer and charge” skills. Timer and charge skill is a type of skill that has a limited effect time and can gain more stack at a certain condition. In the case of dancer skill, effect time is 15s, and Max charge(stack ) is 10. But if you are using more than 1 dancer skill which is “timer and charge”, Max charge of all affecting skills is reduced to (10-number of using skills).

- About how to gain more stack of a skill, you can use it again when effect time remains lower than 5s. If you use it when effect time remains higher than 5s you will lose 1 stack.
All dancer skill limited to dagger, halberd, knuckles, one-handed sword, magic device

Spirited Dance
MP cost: 300
Type: support (active)
Description: A dance to cheer allier up. Immediately restores MP. You can increase the effect by using it again right before the effect ends. The effect goes down if you reuse it too early or gain effect from another dance.
- When using this skill, you will restore MP [50 + (5 * SkillLvl)]
- When this skill is activated, there will be 15 sec duration and start at stack 5 (Max 10 stack)
- When this skill is activated and used again when under 5 sec duration, you will restore MP as twice as the amount depending on what stack you are on.
- If you use it above 4 sec, the stack will be decreased by 1
- But if this skill at under 5 stack, then MP recovery will be lessened MP +([50 + (5 * SkillLvl)] * [20% * stack_aftercast]) {stack_aftercast value cannot exceed 5}
Note: stack_aftercast => if you have 3 stack, and you use it too early, then it is 2 stack then recover mp. But if you use it under 5 sec, then it is 3 stack recover mp first then add 1 stack.
Full Example: If this skill is on 2 stack n use it too early, you will restore 20MP and the stack will be decreased to 1. And then if you use it under 5 sec at 2 stack, you will restore 40MP x 2 = 80MP then gain 1 stack.
